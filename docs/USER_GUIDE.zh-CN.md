# Moyu Translate 操作教程

## 1. 安装

1. 双击 `Moyu Translate.dmg`。
2. 将 `Moyu Translate.app` 拖入 `Applications`。
3. 当前 v0.1.0 使用 ad-hoc 签名。首次启动时，请在 Finder 中右键应用并选择“打开”，再确认一次“打开”。以后可正常从“应用程序”或 Spotlight 启动。
4. 启动后不会出现 Dock 图标；顶部菜单栏会显示 Moyu Translate 猫咪图标。

若 macOS 仍阻止打开，可在终端执行：

```bash
xattr -dr com.apple.quarantine "/Applications/Moyu Translate.app"
open "/Applications/Moyu Translate.app"
```

## 2. 首次授权

Moyu Translate 第一次启动会请求两项系统权限：

- **辅助功能**：监听全局 Option 长按，并优先读取网页、PDF、阅读软件等应用中的可访问文本。
- **屏幕录制**：读取光标附近的一小块屏幕，用于图片、视频、游戏和无法直接访问文字的应用。

可在“系统设置 → 隐私与安全性 → 辅助功能 / 屏幕录制与系统音频”中检查。修改权限后建议退出并重新启动 Moyu Translate。

## 3. 手动查询

1. 在任意应用中长按任一 Option 键约 0.35 秒。
2. 悬浮窗在光标附近出现，输入框自动获得焦点。
3. 输入英文或简体中文，按 Return 翻译。
4. 英文单词优先显示最常用释义；如有其他高频释义，点击向下箭头展开，最多显示三条。
5. 右键翻译结果可复制主译文。

也可以点击菜单栏图标，再选择“打开翻译窗”。

## 4. 光标取词

1. 将光标停在目标文字上。
2. 长按 Option 呼出窗口。应用会记住呼出瞬间的光标坐标。
3. 点击窗口右上角的准星按钮。
4. 应用会临时隐藏窗口，先尝试读取可访问文本；失败时截取光标附近区域并使用 Apple Vision OCR。
5. 识别成功后自动填入输入框并翻译。

受 DRM 保护的视频、系统禁止截图的窗口和部分独占全屏游戏可能无法识别，应用会显示明确错误提示。

## 5. 固定窗口与主题

- 点击图钉按钮可固定悬浮窗；固定后窗口不会因点击其他应用而消失，并会记住拖动后的位置。
- 再次点击图钉解除固定。
- 点击月亮或太阳按钮切换日间/夜间主题，选择会在下次启动时保留。
- 未固定时，点击窗口外部或按 Esc 可收起。

## 6. Apple 离线语言包

内置精简 ECDICT 中的常用单词可直接离线查询并显示多个释义；未命中的单词、短语、句子和中译英使用 Apple Translation。首次使用时，macOS 可能提示下载英中语言包，完成一次下载后即可断网使用。

语言包状态可在菜单栏的“设置 → 离线翻译”中查看。

## 7. 设置

菜单栏图标 → “设置”包含：

- 启用或停用 Option 长按
- 登录时启动
- 自动识别、英译中或中译英
- 日间/夜间主题
- 辅助功能和屏幕录制状态
- ECDICT 与 Apple Translation 状态

## 8. 故障排查

**长按 Option 没有反应**

检查“辅助功能”权限，确认设置中的“启用 Option 长按呼出”已打开，然后重新启动应用。

**准星按钮提示没有权限**

检查“屏幕录制与系统音频”权限。权限修改后需要重启应用，个别情况下需要退出登录后重新进入。

**只翻译单词，句子没有结果**

打开网络完成 Apple 英中语言包的首次下载，之后再断网测试。

**菜单栏图标看不到**

macOS 可能把状态项折叠到控制中心。退出其他菜单栏工具或在控制中心中检查状态项。

## 9. 卸载

1. 从菜单栏选择“退出 Moyu Translate”。
2. 删除 `/Applications/Moyu Translate.app`。
3. 如需清除偏好设置，执行：

```bash
defaults delete com.l3263254135.moyutranslate
```
