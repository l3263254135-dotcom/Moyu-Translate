# 官网运营与基础 SEO

## 1. 网站内容结构

官网首页从上到下保持以下顺序：

1. 产品名、核心动作和 macOS/Windows 下载按钮。
2. 可交互的悬停翻译演示。
3. 网页、PDF、视频、图片和游戏场景。
4. 词典学习结果：主释义、音标、标签、例句和折叠内容。
5. 本地隐私说明。
6. 三步安装教程、系统要求、FAQ 和反馈入口。

不要在首屏堆砌所有功能。用户在 10 秒内只需确认三件事：这是什么、能否支持自己的系统、从哪里下载。

## 2. 每次发版的更新步骤

1. 在 GitHub 创建版本标签并发布 DMG、EXE、MSI 和 SHA-256。
2. 等待 Pages 工作流自动读取 Release 并更新下载清单。
3. 分别点击 macOS 和 Windows 按钮，确认实际文件名和版本号。
4. 在无登录浏览器中下载一次并执行校验。
5. 更新中文、英文更新日志和系统要求。
6. 把同一份更新摘要改写后发布到公众号、小红书和 B 站动态。

下载按钮不得手工填写临时网盘地址。正式入口始终指向项目 GitHub Release，避免旧链接长期传播。

## 3. 基础 SEO

### 页面标题

中文首页：`Moyu Translate - macOS 与 Windows 本地悬浮翻译`  
英文首页：`Moyu Translate - Local hover translation for macOS and Windows`

标题控制在搜索结果可读范围内，不连续堆叠“免费、最好用、神器”等词。

### 元描述

中文建议：`光标停在文字上，长按 Option 或 Alt 即刻翻译。支持网页、图片、视频、PDF 与游戏，本地词典和离线模型不打断你的节奏。`

### 关键词组

- 核心词：Mac 翻译软件、Windows 屏幕翻译、悬浮翻译、OCR 翻译、离线翻译。
- 场景词：PDF 论文翻译、英文游戏翻译、视频字幕翻译、图片取词。
- 品牌词：Moyu Translate、摸鱼翻译。

关键词要自然出现在标题、正文和图片替代文本中，不要在页脚重复几十次。

### 技术检查

- 每个页面只有一个清晰的 `h1`。
- 中英文页面互相设置 `hreflang`。
- 保留 canonical、Open Graph、SoftwareApplication JSON-LD、sitemap 和 robots.txt。
- 图片填写说明性替代文本，截图使用 WebP/AVIF 并保留清晰文字。
- 移动端首屏按钮可点击，正文不出现横向滚动。

## 4. 内容更新频率

- 发版日：更新版本、下载、更新日志和 FAQ。
- 每月：补充一个真实使用场景或教程。
- 每季度：复核系统要求、平台注册流程、截图和竞品描述。
- 出现高频问题时：先更新 FAQ，再在社交平台回复，避免每次重复解释。

## 5. 用户反馈

官网“反馈”链接到 GitHub Issues。Issue 模板要求用户填写：

- 系统版本与设备架构。
- Moyu 版本。
- 发生问题的应用和内容类型。
- 复现步骤、预期结果和实际结果。
- 是否授予辅助功能/屏幕读取权限。

禁止要求用户公开上传含隐私信息的完整截图。建议只截取必要区域，并允许打码。

- [ ] 两个平台下载链接可访问。
- [ ] Release 版本与官网一致。
- [ ] GitHub Issues 已分类并回复。
- [ ] 首页没有失效图片或明显排版问题。
- [ ] FAQ 覆盖本周重复出现的问题。
- [ ] 没有使用未经许可的商业词典正文、字体、音乐或图片。
