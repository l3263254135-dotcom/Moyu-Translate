## 统一定位

一句话定位：**Moyu Translate 是一款本地优先的 macOS 与 Windows 悬浮翻译工具，光标停在文字上，长按 Option 或 Alt 即刻理解。**

三个固定卖点：

- 无需选中，不离开当前窗口。
- 图片、视频、PDF、网页和无边框全屏游戏均可使用。
- 词典、OCR 和语言包在本机运行，不上传查询与截图。

对外表达必须诚实：

- Beta 未正式签名时，必须提示 Gatekeeper/SmartScreen，并提供 SHA-256。
- 不声称内置 Oxford、Cambridge 等商业词典正文。
- Windows 独占全屏、DRM 视频和系统保护内容不保证能够 OCR。
- “完全离线”应表述为“语言包首次下载完成后可离线运行”。

## 首月目标

- 完成官网、GitHub Release、四个平台账号基础资料。
- 发布 2 篇公众号文章、8-10 篇小红书、3 个 B 站视频。
- 获得第一批 30-100 名真实测试用户。
- 收集至少 10 条可复现反馈，并在 GitHub Issues 建立状态。

首月不要以粉丝数作为唯一目标。优先观察：下载按钮点击、安装成功率、首次触发成功率、用户最常见失败场景和愿意再次使用的人数。
