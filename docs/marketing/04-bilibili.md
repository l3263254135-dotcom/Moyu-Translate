# B 站演示视频制作

## 1. 频道设置

头像、名称和简介与官网保持一致。频道介绍建议：`记录 Moyu Translate 的开发、使用技巧和真实兼容性测试。macOS / Windows 本地悬浮翻译。`

建立三个合集：

- 安装与入门。
- 场景演示。
- 版本更新与开发记录。

## 2. 首批视频

1. `3 分钟安装 Moyu Translate：Mac 和 Windows 完整步骤`。
2. `不用选中文本，图片、字幕和游戏怎么直接翻译？`。
3. `Moyu Translate v0.2 更新：25 万词条与双平台版`。

第一个视频解决安装成功率，第二个建立产品认知，第三个让早期用户理解持续更新。

## 3. 录制准备

- 画面：1920×1080、30fps 足够展示工具；游戏演示可使用 60fps。
- macOS 录制：系统截屏工具、OBS Studio。
- Windows 录制：OBS Studio、Xbox Game Bar。
- 剪辑：剪映专业版适合零基础；DaVinci Resolve 适合后续精细制作。
- 音频：安静房间、距离麦克风稳定；没有麦克风时可先做字幕演示。

录制前关闭通知、聊天软件和密码管理器，准备一个不含个人信息的测试账户和示例文件。

## 4. 三分钟安装视频分镜

| 时间 | 画面 | 讲解 |
| --- | --- | --- |
| 0:00-0:08 | 直接展示悬停翻译结果 | 先让观众看到最终效果 |
| 0:08-0:25 | 官网双平台下载区 | 说明只从 GitHub Release 下载 |
| 0:25-1:05 | macOS 安装与权限 | 展示右键打开、辅助功能和屏幕录制 |
| 1:05-1:45 | Windows 安装与提示 | 展示 SmartScreen、EXE 与系统要求 |
| 1:45-2:15 | Option/Alt 触发 | 各演示一次，不重复慢动作 |
| 2:15-2:40 | 下载语言包、断网查询 | 区分词典与句子模型 |
| 2:40-3:00 | 常见问题与反馈 | 放官网、GitHub Issues 和版本号 |

## 5. 剪辑与字幕

- 删除等待下载、寻找文件和重复点击等无信息片段。
- 鼠标移动要慢而明确，关键点击可放大 110%-120%，不要持续追踪放大。
- 字幕一行尽量不超过 22 个汉字，最多两行，避免挡住悬浮窗。
- 命令、按键和菜单路径使用统一颜色；鱼干橙只标记关键动作。
- 背景音乐音量低于人声，不使用来源不明的热门音乐。
- 视频末尾保留 5 秒下载与反馈信息，不放过多二维码。

## 6. 标题和封面

标题模板：`具体收益 + 使用场景 + 产品名`。

- `不用复制粘贴，英文游戏原地翻译｜Moyu Translate`
- `Mac/Windows 屏幕翻译安装教程，3 分钟完成`
- `25 万词条怎么排得不拥挤？Moyu v0.2 开发记录`

封面保留产品悬浮窗、猫咪图标和一句短标题。标题不超过两行，不使用“全网第一”“秒杀所有”等无法证明的表达。

## 7. 发布与维护

- 简介第一段给官网和 GitHub Release。
- 标注测试系统、软件版本和录制日期。
- 添加章节时间点，便于用户直接跳到 Windows 或 macOS。
- 置顶评论记录已知问题和后续修复。
- 版本变化后，在旧视频简介顶部注明最新教程链接，不删除仍有参考价值的视频。
