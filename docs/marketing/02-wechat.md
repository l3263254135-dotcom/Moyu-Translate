# 微信公众号从注册到首月运营

> 微信平台入口和认证政策可能变化。本流程按 2026 年 7 月公开界面整理，提交前以微信公众平台页面为准。

## 1. 注册准备

准备一个未绑定其他公众号的邮箱、可长期接收验证码的手机号、运营者身份证件，以及用于展示的 Moyu 图标和简介。访问微信公众平台，点击“立即注册”。

个人开发者以持续发布教程和更新为主时，优先评估订阅号；需要更强服务入口或企业认证能力时再选择服务号。账号类型一旦确定，迁移成本较高，不要为了“看起来更正式”盲目选择。

建议资料：

- 名称：`Moyu Translate` 或 `Moyu Translate 翻译`。
- 头像：猫咪抱鱼图标，避免加入细小文字。
- 简介：`本地优先的 macOS / Windows 悬浮翻译工具。长按 Option 或 Alt，原地读懂屏幕文字。`
- 自动回复：官网、GitHub 下载、安装教程和反馈入口四个链接。

认证涉及费用和主体材料。首月可以先完成内容和用户验证，再根据菜单、搜索展示和品牌保护需求决定是否认证。

## 2. 内容栏目

每篇文章只解决一个问题。建议四类内容轮换：

1. 安装与使用：权限、语言包、固定窗口、夜间模式。
2. 场景技巧：论文、字幕、图片、英文游戏。
3. 更新公告：新增功能、修复、兼容性限制。
4. 翻译学习：高频易错词、词根、游戏术语和论文术语。

首月每周 1 篇即可，稳定比频繁更重要。

## 3. 零基础排版

- 标题 18-22 字左右，先写用户问题，再写产品名。
- 开头三行直接说明读完能完成什么，不写长篇背景。
- 正文每段 2-4 行；每 300-500 字出现一张截图、步骤图或小标题。
- 正文使用一种强调色，沿用鱼干橙；不要同时使用多种高饱和色。
- 截图裁掉无关桌面内容，隐藏用户名、通知和文件路径。
- 命令、按键、菜单路径使用等宽样式或浅底强调。
- 结尾固定放：下载、完整教程、反馈、下期预告。

发布前在手机预览，检查图片文字是否过小、段落是否拥挤、链接是否可打开。

## 4. 第一篇文章结构

题目：`不用复制粘贴，Moyu Translate 如何在屏幕上直接翻译？`

1. 10 秒动图展示悬停、长按和结果出现。
2. 解释适合 PDF、视频、图片和游戏的原因。
3. 分别给出 macOS 和 Windows 安装步骤。
4. 说明权限、本地处理和 Beta 安全提示。
5. 放 GitHub 下载与问题反馈入口。

## 5. 种子用户与社群

- 从真实使用场景找首批用户：英语学习群、留学生、论文阅读者、独立游戏玩家。
- 先邀请 10-20 位愿意反馈的人，不直接向大群发送广告链接。
- 提供一张“测试任务卡”：安装、触发、查词、OCR、固定窗口，共五项。
- 每周整理一次反馈，不要求用户重复提交已经记录的问题。
- 更新后优先邀请曾报告问题的用户复测，并明确告诉他修复了什么。

## 6. 互动活动

适合首月的小活动：征集“最想翻译却无法选中的场景”。用户提交经过隐私处理的截图，运营者选择 3-5 个场景做兼容性测试并公布结果。奖励可以是内测优先权、贡献者署名或定制词表，不需要现金抽奖。

## 7. 发布检查表

- [ ] 标题说明具体收益。

- [ ] macOS/Windows 步骤没有混写。

- [ ] Beta、安全提示和限制真实准确。
- [ ] 手机预览无小字、截断和隐私信息。
