# Moyu Translate v0.2 Beta 中文操作指南

## 1. 系统要求

- macOS 15 或更高版本，Apple Silicon/Intel。
- Windows 10 22H2 或 Windows 11，x64。
- 首次下载句子翻译语言包时需要网络；下载完成后可断网使用。

## 2. 安装

### macOS

1. 下载 Universal DMG，核对同名 `.sha256` 文件。
2. 打开 DMG，将 `Moyu Translate Beta.app` 拖入“应用程序”。
3. Beta 尚未公证时，首次启动请在 Finder 中右键应用，选择“打开”，再确认一次。
4. 不要长期直接从 DMG 内运行，否则登录启动和权限记录可能不稳定。

### Windows

1. 下载 NSIS EXE 或 MSI，核对同名 `.sha256` 文件。
2. Beta 尚未代码签名时，SmartScreen 可能显示“Windows 已保护你的电脑”。确认文件来自项目 GitHub Release 后，点击“更多信息”再选择“仍要运行”。
3. 普通用户优先使用 EXE；需要 MSI 管理部署时使用 MSI。

## 3. 第一次使用

1. 打开 Moyu，进入设置页。
2. macOS 授予“辅助功能”和“屏幕与系统音频录制”；Windows 无需同名授权，但目标应用必须允许 UI Automation/截图。
3. 在“离线句子翻译”分别下载“英文 → 中文 q8”和“中文 → 英文 q8”。
4. 等待状态显示“已就绪”。Moyu 会断点续传并校验每个模型文件的 SHA-256，此后从本机缓存读取。
5. 历史默认关闭；只有主动开启后才会写入本地数据库。

## 4. 基本操作

1. 把光标停在英文或中文附近。
2. macOS 长按任一 Option，Windows 长按左 Alt，默认约 350ms。
3. 悬浮窗出现在原光标附近并自动聚焦输入框。
4. 直接输入单词/句子并按 Return，也可以完成翻译。
5. 点击准星按钮会读取呼出时保存的光标位置：优先取可访问文本，失败后局部截图 OCR。

Windows 的 `AltGr` 和 `Ctrl+Alt` 不会触发翻译。触发成功后 Moyu 会抑制本次单独 Alt 对应用菜单栏的影响。

## 5. 结果阅读

- 第一行显示单词、音标和朗读按钮。
- 主释义只展示最高频、最有用的义项。
- Oxford 3000、IELTS、TOEFL、GRE 等是学习标签，不是商业词典正文。
- “更多释义、词形变化、例句、同反义词”默认折叠，点击标题展开。
- 星标按钮把符合条件的英文单词或短语加入本地生词本；复制按钮只复制主释义。
- 中译英查询得到不超过 8 个英文词、80 个字符的简短结果时，也可以加入生词本；应用会结合离线词典的短语词条与词性识别完整句子，完整句子不会进入复习队列。
- 顶部“生词本与历史”按钮可搜索生词和已开启的历史，点击生词会重新查询最新释义；历史可一键清空。

## 6. 生词本与卡片复习

1. 查词后点击星标，结果显示“已加入生词本”即保存成功；再次点击可移除。
2. 打开“生词本与历史”，可查看全部、今日待复习和已掌握数量，并按“全部、待复习、已掌握”筛选。
3. 点击“开始复习”进入卡片模式，每轮最多载入 20 个到期词。
4. 卡片正面显示英文、音标和朗读按钮；点击“显示释义”后查看主释义、词性和首条例句。
5. 选择“认识”后，复习间隔按 1、3、7、14、30、60 天递增；阶段达到 5 后标记为“已掌握”。
6. 选择“不认识”会把词重置并安排在 10 分钟后复习，在当前轮最多重新出现一次。
7. 生词和复习进度只保存在 `moyu-user.sqlite`，无需账户，也不会上传。

从 `v0.2.0-beta.1` 升级时，原有收藏会自动迁移。符合单词/短语规则的条目直接进入复习队列，旧句子收藏继续保留浏览但不参与卡片复习。

## 7. 窗口与主题

- 月亮/太阳按钮切换日间和夜间主题。
- 图钉按钮固定窗口；固定后失去焦点不会自动收起。
- 未固定时点击其他应用或按 Escape 会收起悬浮窗。
- 多显示器和高 DPI 环境会自动把窗口限制在光标所在屏幕边缘内。

## 8. 常见问题

### 长按没有出现窗口

- 检查设置中的“启用 Option/Alt 长按呼出”。
- macOS 检查辅助功能权限，修改权限后完全退出并重新打开 Moyu。
- Windows 不要使用 AltGr、Ctrl+Alt 或同时按其他键。

### 准星无法识别

- 先在目标文字上长按呼出，再点击准星；直接启动应用后没有原始锚点。
- macOS 检查屏幕录制权限。
- Windows 安装需要的 OCR 语言；游戏优先切换无边框窗口模式。
- DRM 视频、系统保护窗口和独占全屏内容可能禁止截图，Moyu 会返回明确错误。

### 句子翻译提示下载失败

- 确认首次下载时网络可访问模型仓库。
- 点击“重试”；完成前不要退出应用。
- 下载成功后再断网测试。下载中断会从本机临时数据继续；哈希不匹配时该文件不会进入可用缓存。
- 如需释放空间，在设置页点击已就绪语言包右侧的删除按钮。

### 生词没有出现在今日复习中

- 新词默认可立即复习；完成评分后会按下一次到期时间出现。
- “不认识”的词会在 10 分钟后再次到期，当前轮只回队一次。
- 从旧版本迁移的完整句子仅供浏览，不进入复习队列。

### 卸载

- macOS：退出应用，删除“应用程序”中的 App；如需清除生词本、复习进度和设置，再删除对应应用数据目录。
- Windows：在“设置 → 应用 → 已安装的应用”卸载；用户数据库和模型缓存可在确认不再需要后删除。
